从明确目标开始，把 AI 工具变成可复用的工作流程。这篇示例展示本站教程的基本写法。

<!-- more -->

## 第一步：明确目标与准备环境

写教程时，先说明适用系统、工具版本、输入材料和预期结果。

> 提示：不要向 AI 工具粘贴密码、API 密钥或未经授权的个人信息。执行任何命令前，请先理解它的作用。

下面的命令只查看版本，不会修改系统。可使用代码块右上角按钮复制。

```bash
node --version
npm --version
git --version
```

## 第二步：编写可复用的提示词

将目标、上下文、约束和输出格式分开，方便反复使用。

```text
目标：把以下技术笔记整理成适合新手的教程。
上下文：读者掌握基础电脑操作，但没有编程经验。
要求：按第一步、第二步、第三步组织；解释命令用途；不要编造结果。
输出：准备条件、操作步骤、验证方法、常见问题。
输入笔记：[在这里粘贴已脱敏的笔记]
```

### 验证清单

- 首页是否显示文章标题、封面和简介？
- 右侧目录是否能定位到对应小节？
- 代码复制结果是否与代码块内容一致？
- 点击导航栏搜索，输入“提示词”能否找到本文？

## 常见问题

**图片不显示？** 检查文件是否位于 source/img/，路径和大小写是否一致。

**搜索找不到新文章？** 重新生成静态文件，再刷新页面。搜索索引会随构建更新。

**准备正式发布？** 先把根目录配置中的 url 改为自己的真实域名，再重新生成。
